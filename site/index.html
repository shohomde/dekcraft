A FEW GOOD QUESTIONS

Before you
make room.

Does the website filter my YouTube feed?+

The website is a playground with sample recommendations. Install the extension to filter YouTube Home and Watch-page recommendations. You can export preferences from the playground and import them into the extension’s Settings.

Is semantic matching perfect?+

No. Dekcraft uses the small, quantized all-MiniLM-L6-v2 embedding model. It matches titles and topic examples by similarity. English works best; ambiguous titles can be missed or overblocked. Review hidden videos and adjust sensitivity to suit you.

Does it change YouTube’s algorithm?+

Dekcraft hides cards on the page you see. It does not retrain YouTube’s recommendation system or send “Not interested” feedback. YouTube layouts can change, so some recommendations may not be detected.

Why do I need Developer mode?+

This is an early release distributed directly from this project, not a Chrome Web Store listing. Developer mode lets you load the extracted extension. Future updates require downloading the new version and reloading it in the Extensions page.

Can I use this on my phone?+

The playground works on small screens, but the extension is for Chromium-based desktop browsers. It does not filter the YouTube mobile app.
